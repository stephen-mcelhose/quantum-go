# Package Documentation

The Go port is organized into three core packages to maintain a clean separation of concerns and avoid circular dependencies.

## 1. `math`
The foundation for linear algebra and thermodynamics.
- **Matrix**: Uses a flat `[]complex128` slice for optimal performance.
- **Operations**: `Mul`, `Tensor`, `ConjugateTranspose`, `IdentityMatrix`, `Exp`.
- **Thermodynamics**: `ToDensityMatrix`, `PartialTrace`, `ExpectationValue`, `VonNeumannEntropy`.
- **Fuzzing**: Includes property-based tests for matrix dimensions and multiplication.

## 2. `core`
The domain model for quantum circuits.
- **Gate**: Interface for all quantum operations. Includes `ApplyOptimize` for specialized gate logic.
- **TimeEvolution**: Unitary evolution $e^{-iHt}$ generated by a Hamiltonian.
- **Step**: A container for gates that can be executed in a single time slice.
- **Program**: The complete quantum circuit.
- **Block / BlockGate**: Support for composite gates (e.g., Fourier, Add).
- **Result**: Interface for execution outcomes.
    - **CompactResult**: Stores final state only (default).
    - **InstrumentedResult**: Stores intermediate states for debugging/analysis.
- **Qubit**: Model for measurement results and state probabilities.

## 3. `local`
The simulation engine.
- **ExecutionEnvironment**: Runs a `Program` and produces a `Result`.
- **Computations**: Contains the optimized gate application logic, including bit-manipulation for standard gates and recursive execution for `BlockGate`s.
- **Integration**: Initializes `core.GlobalStepExecutor` to allow `BlockGate`s to simulate themselves using the local engine.
