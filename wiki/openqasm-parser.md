# OpenQASM Parser

`qasm/parser.go` implements a subset-OpenQASM 2.0 parser that converts QASM 2.0 text into a `core.Program`. This enables quantum-go to import circuits generated by Qiskit, IBM Quantum, and other tools. The parser is intentionally lightweight — it handles the common gates without implementing the full QASM specification.

## Entry Point

```go
func Parse(input string) (*core.Program, error)
```

Returns a `*core.Program` ready to run, or an error if no `qreg` line is found.

## Parsing Strategy

Line-by-line scan using regex:

1. **Skip lines:** blank, `//` comments, `OPENQASM`, `include`, `barrier`
2. **Split by `;`:** handles multiple gates per line
3. **`qreg q[N]`** — creates the Program with N qubits; must appear before any gates
4. **`measure q[i] -> c[j]`** — adds `Measurement(i)` gate
5. **Gate regex:** `([a-z0-9]+)(\((.*)?\))? q[\d]+(, q[\d]+)?(, q[\d]+)?`
   - Group 1: gate name
   - Group 3: parameter (e.g., `"1.5707"` for angle)
   - Groups 4, 6, 8: qubit indices q0, q1, q2

Each gate line is parsed into a `core.NewStep(gate)` added to the program.

## Supported Gate Mapping

| QASM mnemonic | Params | core constructor                        | Notes                                     |
| ------------- | ------ | --------------------------------------- | ----------------------------------------- |
| `h`           | —      | `NewHadamard(q0)`                       |                                           |
| `x`           | —      | `NewX(q0)`                              |                                           |
| `y`           | —      | `NewY(q0)`                              |                                           |
| `z`           | —      | `NewZ(q0)`                              |                                           |
| `s`           | —      | `NewS(q0)`                              |                                           |
| `sdg`         | —      | `NewS(q0).SetInverse(true)`             | S-dagger (S†)                            |
| `t`           | —      | `NewT(q0)`                              |                                           |
| `tdg`         | —      | `NewT(q0).SetInverse(true)`             | T-dagger (T†)                            |
| `sx`          | —      | `NewV(q0)`                              | √X = V gate                              |
| `rx(θ)`       | θ      | `NewRx(theta, q0)`                      |                                           |
| `ry(θ)`       | θ      | `NewRy(theta, q0)`                      |                                           |
| `rz(θ)`       | θ      | `NewRz(theta, q0)`                      |                                           |
| `id`          | —      | `NewIdentity(q0)`                       |                                           |
| `cx`          | —      | `NewCnot(q0, q1)`                       | CNOT (cx = controlled-X in QASM)         |
| `cz`          | —      | `NewCz(q0, q1)`                         |                                           |
| `swap`        | —      | `NewSwap(q0, q1)`                       |                                           |
| `ccx`         | —      | `NewToffoli(q0, q1, q2)`               | Toffoli (Controlled-Controlled-X)        |
| `u1(θ)`       | θ      | `NewPhaseShift(theta, q0)`              | QASM u1 = PhaseShift                     |
| `u3(θ,φ,λ)`   | θ,φ,λ  | `NewU(theta, phi, lambda, q0)`         | Universal 3-param gate                   |
| `u(θ,φ,λ)`    | θ,φ,λ  | `NewU(theta, phi, lambda, q0)`         | QASM 3.0 u = same as u3                 |
| `cu1(θ)`      | θ      | `NewCr(q0, q1, theta)`                  | Controlled phase shift                   |
| Unknown       | —      | `fmt.Printf("Warning: Skipping…")`    | Skipped with warning, not error          |

## Limitations

The parser does **not** support:
- Custom gate definitions (`gate my_gate(...) { ... }`)
- Classical conditionals (`if (c == 0)`)
- Multi-qubit registers referenced as `q[0..3]` ranges
- `creg` classical registers (measurement results are not stored)
- QASM 3.0 syntax beyond `u(θ, φ, λ)`
- `barrier` (explicitly skipped)

For QASM circuits using custom gates, they must be manually decomposed into supported primitives before import.

## Example

```qasm
OPENQASM 2.0;
include "qelib1.inc";
qreg q[2];
h q[0];
cx q[0], q[1];
measure q[0] -> c[0];
measure q[1] -> c[1];
```

Parses to:
```go
p = core.NewProgram(2)
p.AddStep(core.NewStep(core.NewHadamard(0)))
p.AddStep(core.NewStep(core.NewCnot(0, 1)))
p.AddStep(core.NewStep(core.NewMeasurement(0)))
p.AddStep(core.NewStep(core.NewMeasurement(1)))
```

## Error Handling

- `no qreg found in QASM input` — returned if no valid `qreg q[N]` line is seen
- Unknown gates: warning printed to stdout, gate skipped (program continues)
- Malformed parameters: `strconv.ParseFloat` failure returns 0.0 (silent)

## Key Points

- Parse creates one `core.NewStep(gate)` per gate — gates within the same QASM line are not parallelized into a single step.
- The `measure` branch is handled before the general gate regex to avoid misparse.
- `sdg`/`tdg` use `SetInverse(true)` on the gate after construction — the same inverse flag from [[rotation-implementations]].
- `sx` maps to V gate (√X) — the naming difference is QASM vs quantum-go convention.
- `u1` → `PhaseShift` (not the full U gate), consistent with the QASM 2.0 spec where u1 has 1 angle.
- `cu1` → `CR` (Controlled Rotation) — the controlled phase gate from [[rotation-implementations]].
- For the full gate vocabulary defined in `qelib1.inc` and which gates quantum-go supports, see [[qelib1-standard-gates]].
